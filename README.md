# Comparative Analysis of L1 and L2 Regularization
### CS587 — Machine Learning | ITU Lahore | MS Data Science

## 🎯 Project Overview
A comprehensive comparative study of L1 (Lasso) and L2 (Ridge) 
regularization techniques applied to the Ames Housing Dataset, 
evaluating their impact on model performance, feature selection, 
and overfitting prevention.

## 📊 Dataset
- **Dataset**: Ames Housing Dataset
- **Features**: 80+ housing attributes
- **Target**: House Sale Price
- **Size**: 2,930 records

## 🔬 What's Compared
- L1 Regularization (Lasso) — sparse solutions, feature selection
- L2 Regularization (Ridge) — weight shrinkage, handles multicollinearity
- ElasticNet — combination of both
- Baseline Linear Regression — no regularization

## 📈 Key Results
- L1 reduced features from 80+ to most impactful predictors
- L2 achieved better generalization on dense feature sets
- Regularization paths visualized across alpha values
- 16 comprehensive visualizations generated
